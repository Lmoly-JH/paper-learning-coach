# 论文拆解 + 术语解释 + 背景知识补全 + 学习路线

这是一个面向科研初学者的 Codex skill。它的核心不是简单总结论文，而是先识别“读懂这篇论文需要哪些前置知识”，补齐知识空白，再进行论文拆解、术语解释、公式与图表解读，并生成后续学习路线。

## 使用方式

将本目录作为 Codex skill 安装后，可以显式调用：

```text
$paper-learning-coach 请从零基础开始帮我读这篇论文，先补齐理解所需的背景知识。
```

也可以直接上传论文 PDF、提供论文链接/DOI，或粘贴具体段落、公式和图表。

## 设计重点

- 先做知识空白审计，再做论文摘要
- 将概念分成“必须先知道 / 知道更好 / 高级扩展”
- 每个术语同时给出通俗解释、专业定义、例子和本文语境
- 区分论文原文结论、合理推断和外部背景知识
- 最后给出学习路线、检索关键词和自测题
